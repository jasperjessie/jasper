## The problem this solves

Without a defined competency framework, "good performance" means whatever each evaluator personally thinks it means — which makes feedback inconsistent, progression decisions hard to defend, and growth difficult to track over time. A framework replaces that with a shared, observable definition of what each level of competence actually looks like.

One example of this approach in practice: the [SEL competency domains](/services/assessment-learning-analytics) I use for social-emotional assessment are themselves a competency framework — five defined domains, each broken into observable, ratable indicators, with clear score bands for interpretation. The same underlying method (define the domain → specify observable behaviors → set interpretable bands) applies whether the competencies are academic, social-emotional, or professional/faculty-facing.
